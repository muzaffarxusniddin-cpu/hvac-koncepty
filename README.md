# HVAC Group — концепты главной страницы

Статические концепты первого экрана hvacgroup.uz. Сборки нет: это самодостаточные
HTML-файлы, в которые вшиты шрифты, изображения и библиотеки.

| Файл | Что это |
|---|---|
| `index.html` | Страница сравнения двух веток, точка входа |
| `konsept-C4-shourum.html` | Ветка «Шоурум»: герой на рендере зала, виртуальный тур 360°, лента из семи ракурсов |
| `konsept-C3-panel.html` | Ветка «Панель»: герой на принципиальной схеме отопления |
| `vercel.json` | Заголовки: noindex, must-revalidate, базовая безопасность |

## Публикация на Vercel

Проект без фреймворка и без шага сборки.

1. Vercel → **Add New** → **Project** → **Import Git Repository**
2. Выбрать этот репозиторий
3. **Framework Preset:** Other
4. **Build Command:** оставить пустым
5. **Output Directory:** оставить пустым (корень репозитория)
6. **Deploy**

Дальше каждый `git push` в `main` publишится автоматически. Пуш в другую ветку
даёт превью-ссылку — удобно показывать варианты, не трогая основную.

## Важно

`vercel.json` отдаёт `X-Robots-Tag: noindex, nofollow`. Черновик не попадёт
в поисковую выдачу и не помешает будущему продвижению домена. Перед настоящим
запуском этот заголовок нужно убрать.

## Что это не является

Первый экран, а не готовый сайт: логотип — типографская заглушка, тексты
черновые, ссылки в меню никуда не ведут, фотографий объектов нет.
