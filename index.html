  • Виртуальный тур грузится только по клику
  • Семь ракурсов в AVIF: полный кадр 36–54 КБ
  • Схема системы вынесена во второй экран

C3 · Панель

  • Фон — шейдер с дизерингом, не картинка
  • Схема сведена по геометрии после аудита
